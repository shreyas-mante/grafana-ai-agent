# Deploy PulseAgent for free (about 30 minutes)

```
Your apps ──errors (SDK, ingest key)──▶ Render: PulseAgent (free) ──▶ Neon Postgres (free)
Grafana alerts ──webhook──────────────▶        │
Widget on your sites ─────────────────▶        ├─ queries ▶ Grafana Cloud: Prometheus, Loki, Tempo (free)
                                               ├─ reads   ▶ GitHub (read-only token)
                                               ├─ asks    ▶ Gemini / Groq (free) or Claude / OpenAI (your key)
                                               └─ posts   ▶ Slack
```

Never paste keys or tokens into chat, code or git: only into the services' own settings pages, or PulseAgent's **Settings** page, which encrypts them.

## 1. Neon Postgres (3 min)
1. Sign up at https://neon.tech (free, no card) and create a project.
2. Copy the **connection string**. It looks like `postgresql://user:password@ep-xxx.region.aws.neon.tech/neondb?sslmode=require`.

## 2. Render (10 min)
1. Sign up at https://render.com with GitHub. Give it access to **only** the `grafana-ai-agent` repo.
2. Choose **New**, then **Blueprint**, select the repo, then **Apply**. It reads `render.yaml`.
3. Fill in:
   - `DATABASE_URL`: the Neon connection string
   - `APP_PUBLIC_URL`: `https://<name>.onrender.com` (you can set it after the first deploy)
   - `APP_SESSION_SECRET` and `APP_ENCRYPTION_KEY` are generated by Render. **Don't change `APP_ENCRYPTION_KEY` later**: it decrypts the integration secrets you save.
   - Optional: `APP_ADMIN_KEY_SHA256` / `APP_INGEST_KEY_SHA256` from `scripts/gen-prod-keys.sh`, if you want a bootstrap API key.
4. The first build takes about 5–8 minutes.

## 3. Create your account
Sign-up is **invite-only** by default (`APP_SIGNUP=invite`), so strangers can't create workspaces on your server. For your first account, either:
- **Option A:** temporarily set `APP_SIGNUP=open` in Render, sign up at your URL (this creates your workspace and makes you its owner), then set it back to `invite`.
- **Option B:** set the bootstrap key hashes in step 2, choose **API key** on the sign-in page with `PROD_ADMIN_KEY`, then go to **Settings**, then **Members**, then **Invite**, and open the link to create your password account.

Invite teammates from **Settings**, then **Members**. Links work once and expire in 7 days.

## 4. Connect integrations (in the app: Settings → Integrations)
Each card has a **Test connection** button.

| Integration | Free option | What to enter |
|---|---|---|
| AI provider | **Gemini** (aistudio.google.com/apikey) or **Groq** (console.groq.com, provider `openai`, base URL `https://api.groq.com/openai/v1`, model `llama-3.3-70b-versatile`) | Provider, model, key. Claude: provider `anthropic` (default model `claude-opus-5-5`, paid). Free tiers may use your prompts for training, so use a paid key for confidential code. |
| Prometheus | Grafana Cloud free stack | Query URL ending in `/api/prom`, the instance ID as username, a **metrics:read** token |
| Loki | Same Grafana Cloud stack | Loki URL, user ID, **logs:read** token |
| Tempo | Same Grafana Cloud stack | Tempo URL, user ID, **traces:read** token |
| Grafana | Your Grafana | URL plus a **Viewer** service account token |
| Source code | GitHub | `owner/repo` plus a fine-grained token with Contents: read and Pull requests: read. Code package prefixes, e.g. `com.acme`. Optional: an **Issues: write** token for approved actions. |
| Slack | Slack incoming webhook | Webhook URL and "Notify for" (alerts / all / none) |
| Remediation | Your own automation (e.g. a CI job) | HTTPS webhook URL plus a signing secret. Approved actions arrive signed: `X-PulseAgent-Signature: sha256=HMAC(secret, timestamp + "." + body)`. |

Also add your **service map** in Settings → Service map, so the agent knows dependencies.

## 5. Connect your apps (in the app: Settings → API keys)
- **ingest** key: for the Spring Boot SDK (`pulseagent.ingest-key`) and the Grafana alert webhook (`Authorization: Bearer <key>`)
- **admin** key: for your own scripts calling the REST API
- **widget** key: for embedding the chat widget; list the exact sites (origins) allowed to use it

The **Integrate** page has copy-paste snippets.

## 6. Try the demo against your live server
In `~/grafana-ai-agent/.env.local`, add:
```bash
PULSEAGENT_ENDPOINT=https://<name>.onrender.com
PULSEAGENT_INGEST_KEY=<an ingest key from your live workspace>
# Optional: forward demo metrics to Grafana Cloud (metrics:write token)
GC_REMOTE_WRITE_URL=https://prometheus-prod-XX-prod-XX.grafana.net/api/prom/push
GC_USERNAME=<instance ID>
GC_WRITE_TOKEN=<metrics:write token>
```
Then run `scripts/dev.sh`, then `scripts/chaos.sh on`, and open **Errors**, then **Investigate** on your live site.

## Free-plan limits
- Render sleeps after 15 minutes idle (the first request takes about 30–60 s). All data lives in Neon, so nothing is lost.
- Neon free: 0.5 GB. Investigations older than 30 days are pruned automatically.
- Free AI tiers have per-minute limits. Scheduled checks every hour or slower are safest.

## Rotating secrets
- **API keys:** revoke in Settings → API keys, then create new ones.
- **Integration tokens:** revoke on the provider's site, then paste the new one in Settings.
- **Bootstrap keys:** `scripts/gen-prod-keys.sh --force`, update the hashes in Render.
