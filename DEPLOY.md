# Deploy PulseAgent for free (about 30 minutes)

```
Your Mac (demo app + Prometheus) ──metrics──▶ Grafana Cloud (free Prometheus)
        │                                               ▲
        └──errors (SDK, ingest key)──▶ Render (PulseAgent, free) ──queries──┘
                                           │ reads code ▶ GitHub (read-only token)
                                           │ asks AI    ▶ Gemini (free key)
```

Everything below is free. Never paste keys or tokens into chat, code or git: only into the services' own settings pages.

## 1. Production keys (1 min)
```bash
cd ~/grafana-ai-agent && scripts/gen-prod-keys.sh && cat .env.production
```
Save `PROD_ADMIN_KEY` and `PROD_INGEST_KEY` in your password manager. You'll paste the two `*_SHA256` hashes into Render.

## 2. Gemini key (2 min)
Go to https://aistudio.google.com/apikey, choose **Create API key**, and keep it for step 5.
Free-tier prompts may be used by Google to improve its products, so this tier is for your own demo, not other companies' code.

## 3. Grafana Cloud free Prometheus (8 min)
1. Sign up at https://grafana.com/auth/sign-up (free plan, no card).
2. In the Cloud portal (grafana.com, then **My Account**), open your stack and choose **Prometheus**, then **Details**. Note:
   - **Remote Write Endpoint**, e.g. `https://prometheus-prod-XX-prod-XX.grafana.net/api/prom/push`
   - **Username / Instance ID**, a number
   - Your **query URL** is the same endpoint **without `/push`**: `https://prometheus-prod-XX-prod-XX.grafana.net/api/prom`
3. In **Security**, then **Access Policies**, create two policies (least privilege):
   - `pulseagent-read` with scope **metrics:read**, then **Add token**. This one goes to Render.
   - `local-write` with scope **metrics:write**, then **Add token**. This one goes to your Mac.

## 4. GitHub read-only token (3 min)
Go to GitHub **Settings**, then **Developer settings**, then **Fine-grained tokens**, then **Generate new token**:
- Repository access: **Only select repositories**, then `grafana-ai-agent`
- Permissions: **Contents: Read-only**, **Pull requests: Read-only** (Metadata is added automatically)
- Expiration: 90 days

## 5. Render (10 min)
1. Sign up at https://render.com with GitHub. When asked, give access to **only** the `grafana-ai-agent` repo.
2. Choose **New**, then **Blueprint**, select `grafana-ai-agent`, then **Apply**. It reads `render.yaml` (free plan, Docker).
3. Fill in the secret values:

| Variable | Value |
|---|---|
| `APP_ADMIN_KEY_SHA256` | from `.env.production` |
| `APP_INGEST_KEY_SHA256` | from `.env.production` |
| `GEMINI_API_KEY` | step 2 |
| `APP_PROMETHEUS_URL` | Grafana Cloud query URL (ends in `/api/prom`) |
| `APP_PROMETHEUS_USERNAME` | Grafana Cloud instance ID |
| `APP_PROMETHEUS_TOKEN` | the **metrics:read** token |
| `APP_GITHUB_REPO` | `shreyas-mante/grafana-ai-agent` |
| `GITHUB_TOKEN` | step 4 |

`APP_SESSION_SECRET` is generated by Render automatically.
4. The first build takes about 5–8 minutes. Then open `https://<name>.onrender.com` and sign in with `PROD_ADMIN_KEY`.
   The sidebar should show **AI: gemini-…**, **Code: github**, and your Grafana Cloud host.

## 6. Point the demo at it (2 min)
Add these lines to the **end** of `~/grafana-ai-agent/.env.local`:
```bash
GC_REMOTE_WRITE_URL=<Remote Write Endpoint from step 3>
GC_USERNAME=<instance ID>
GC_WRITE_TOKEN=<the metrics:write token>
PULSEAGENT_ENDPOINT=https://<name>.onrender.com
PULSEAGENT_INGEST_KEY=<PROD_INGEST_KEY>
```
Then:
```bash
scripts/dev.sh            # metrics go to Grafana Cloud, errors go to Render
scripts/chaos.sh on       # break the payment service
```
Wait about 1 minute, open your Render URL, go to **Errors**, and choose **Investigate**.

## 7. Optional: auto-investigate Grafana alerts
In Grafana Cloud go to **Alerting**, then **Contact points**, then **Add contact point**, then **Webhook**:
- URL: `https://<name>.onrender.com/api/v1/webhooks/grafana`
- Authorization header: `Bearer <PROD_INGEST_KEY>`

## Free-plan limits
- Render sleeps after 15 minutes idle. The first request then takes about 30–60 s, and investigations and errors kept in memory reset. Runbooks in `knowledge/` reload on start.
- Gemini's free tier has per-minute limits. If you hit one, the app tells you to wait a minute.

## Rotating a leaked key
Run `scripts/gen-prod-keys.sh --force`, update the two hashes in Render, and redeploy. Old keys stop working immediately. For Gemini, GitHub or Grafana tokens, revoke them on that service's page and paste new ones into Render.
